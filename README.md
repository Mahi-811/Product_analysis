
# Product Analytics Dashboard

## Overview
Built an end-to-end product analytics solution using MySQL, Python, and Power BI to analyze user behavior, retention, funnel conversion, and revenue performance.

## Tech Stack
- MySQL
- Python (Pandas, NumPy)
- Power BI

## Dataset
- 10,000 users
- 55,000 sessions
- 33,000 events
- 1,382 orders

## Analyses Performed
### Funnel Analysis
Tracked user progression from app open to purchase.

### Cohort Retention Analysis
Measured monthly retention across user cohorts.

### Revenue Analysis
Analyzed revenue trends and business KPIs.

## Key Insights
- Conversion Rate: 13.8%
- Month 1 Retention: ~40%
- Largest drop-off occurred before purchase
- Revenue concentrated among high-value cohorts
